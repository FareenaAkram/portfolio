## Getting Started

```bash
# Clone the repo
git clone https://github.com/FareenaAkram/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run locally
npm run dev

# Build for production
npm run build
```

Open [http://localhost:5173](http://localhost:5173) to view it in the browser.
